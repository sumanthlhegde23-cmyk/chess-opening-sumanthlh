# Stockfish Web Engine

This directory contains the unmodified Stockfish 19 lite single-threaded WebAssembly build from Stockfish.js. The worker script loads `stockfish.wasm` from this directory.

- Project and corresponding source: https://github.com/nmrugg/stockfish.js/tree/v19.0.0
- License: GNU General Public License version 3, in `Copying.txt`
- Build variant: `stockfish-19-lite-single`
